# Tables 12 and 13 Supporting Data: AutoGen Distributed Group Chat Static Instrumentation-Effort Measurement

This document records static instrumentation-effort data for the AutoGen Distributed Group Chat target.

| Variant | File |
|---|---|
| ABT | `src/experiments/autogen_group_chat_abt/instrumented_agent.py` |

## Counting Note

The ABT measurement includes the shared semantic node instrumentation helper, and the direct OI/Otel measurement includes both the shared direct node recorder and semantic node instrumentation helper. These files contain trace-generation logic required by the corresponding instrumentation variants. The values in this table are generated by the AST-based measurement script recorded in `table-12-13-automated-measurement-supporting-data.md`.

The AutoGen adapter uses group-chat-specific node instrumentation without the book-assembly evaluator added for the CrewAI flow target. This keeps the AutoGen measurement target-specific while preserving the same ABT/direct OI equivalence protocol.
