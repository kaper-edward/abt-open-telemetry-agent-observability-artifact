# Tables 12 and 13 Supporting Data: Open Deep Research Static Instrumentation-Effort Measurement

This document records static instrumentation-effort data for the Open Deep Research target.

## Measurement Target

| Variant | File |
|---|---|
| ABT | `src/experiments/open_deep_research_node_abt/instrumented_agent.py` |
| Direct OI/Otel | `src/experiments/open_deep_research_node_oi/instrumented_agent.py` |

The public source target is the pinned Open Deep Research source package under `src/experiments/_evaluation_resources/target_agent_references/open_deep_research/source/src/open_deep_research`. The experiment executes the original source graph with controlled LLM and tool dependencies. The source target contains 1,755 non-empty, non-comment LOC, which is used as the denominator for the instrumentation code ratio.

## Measurement Results

| Metric | ABT | Direct OI/Otel | ABT as % of Direct OI/Otel |
|---|---:|---:|---:|
| Non-empty non-comment LOC | 214 | 375 | 57.1% |
| Instrumentation code ratio | 12.2% | 21.4% | 57.1% |
| Instrumentation call-site count | 13 | 28 | 46.4% |
| Instrumentation API argument count | 22 | 75 | 29.3% |

## Counting Note

The LOC values count non-empty, non-comment lines in the instrumentation code. Instrumentation call-site count counts call sites that create or populate trace elements and spans. Instrumentation API argument count counts explicit information items supplied at those call sites, including nested trace fields in dictionaries. Code ratio is computed as instrumentation LOC divided by the pinned Open Deep Research source-target LOC. This ratio should be interpreted as instrumentation effort relative to the evaluated public source graph, not as invasive edits inside the upstream repository. The values in this table are generated by the AST-based measurement script recorded in `table-12-13-automated-measurement-supporting-data.md`.
